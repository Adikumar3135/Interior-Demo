GRANDEUR INTERIORS — DEMO WEBSITE
=================================
Open index.html in a browser, or upload the entire folder to a static host.

Pages included:
Home, Products, Kitchens, Wardrobes, Appliances, Furniture, Office,
Brands, Kontract, About Us, Contact Us, Careers, Book a Visit.

Features:
- Animated full-screen loading intro on each page
- Responsive desktop and mobile layouts
- Full-screen menu with page navigation
- Editorial luxury-interior visual style inspired by the supplied reference screenshots
- Demo enquiry / booking forms with front-end confirmation only
- Scroll and hover transitions, reduced-motion accessibility support

Notes:
- Interior photography and Google Fonts load from external services, so internet is needed for those assets.
- Forms are front-end demo only. Connect an API/backend to receive submissions.
- Replace demo copy, brand names, contact details and images with client-approved content before production.
